📊 Financial Analysis – Excel Project
📌 Project Overview

This project presents a comprehensive financial performance analysis across multiple countries, fiscal years, and business regions using Microsoft Excel.
The dashboard evaluates Net Sales, COGS, Gross Margin, and Gross Margin % trends to understand profitability, regional performance, and year-over-year growth.

The analysis is built using pivot tables, filters, and summarized financial statements to transform raw financial data into actionable business insights. 

financial_analysis_project

🎯 Business Objectives

The main goals of this project are:

Analyze financial performance by country, region, and fiscal year

Track year-over-year growth in Net Sales and Gross Margin

Identify high-profit and low-profit markets

Monitor monthly and quarterly financial trends

Evaluate Gross Margin % variation across sub-zones and time

Fiscal years: 2019, 2020, 2021
